# ZCU102 support

This package provides working PYNQ-Z1 sources and examples. It does not contain a runnable ZCU102 build. The images target `xc7z020clg400-1`, while ZCU102 uses a Zynq UltraScale+ MPSoC described in the [AMD board guide](https://docs.amd.com/v/u/en-US/ug1182-zcu102-eval-bd).

To port the experiments, create a Vivado design for the actual ZCU102 board revision. Replace the PS7 integration with the UltraScale+ processing system and configure its AXI connection, clocks and resets.

Configure each solver from the parent 100-instance software package. Update the dimensions, couplings or clauses, targets, state widths, counters and ROM addresses. A counter that represents 32 needs six bits. The `sat_n32_i03` case needs five-bit break indices and 32,768 mass entries.

Update the host runner's fixed 26-variable checks, scoring, register map and clock access. The supplied metadata adapter and reset validator are specific to PS7. Build each configured design and check utilization and timing. Export matching BIT and HWH files as described in the [PYNQ overlay guide](https://pynq.readthedocs.io/en/v3.1/pynq_overlays/loading_an_overlay.html).

Provide a compatible ZCU102 boot image and runtime. Compare one paired trial per family with the software model before running the collection. Retain the build reports, image hashes and raw board results.
